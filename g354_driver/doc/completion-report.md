## ZUPT 零偏跟踪测试 (2026-07-30)

使用 38 字节 polling 模式 + Mahony(Kp=1.0, Ki=0.005) + ZUPT 静止检测。

| 指标 | 值 |
|:-----|:----|
| 静置时长 | 132 s |
| 总 yaw 漂移 | 0.005 ° |
| 漂移率 | 0.006 °/min |
| 陀螺 Z 残余零偏 | < 0.0001 °/s |
| 加速度噪声 | σ = 0.0015 g |
| 帧率 | 87.7 Hz |

结论: 静置状态下 yaw 漂移已消除。运动中漂移需 Phase 1 轮速融合解决。

## 已知的可优化方向

1. 运动中 yaw 漂移 → 需 Phase 1 EKF 融合轮速里程计
2. 用 EKF 版代替 Mahony 可在线跟踪零偏温漂
3. 增加 `/imu/raw` 话题发布原始未滤波数据，便于调试
