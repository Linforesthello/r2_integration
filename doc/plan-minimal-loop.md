# 最小闭环打通计划（建图→导航→自动运动→避障）

> 制定: 2026-08-06
> 原则: 先端到端，再优化（全局 CLAUDE.md 项目推进原则）
> 目标: **3 周内跑通"地图→发 goal→车自主到达→动态避障"最小闭环**（本地场地）
> 状态: 待执行

---

## 一、目标与范围

### 做（3 周冲刺）
1. 场地地图录制与复用（KISS-ICP 点云 → 2D 占用网格）
2. Nav2 最小导航闭环（发 goal → 规划 → 底盘执行 → 到达）
3. 动态避障（local costmap + 人/障碍物绕行）

### 不做（闭环通了再谈）
- 不磨 EKF/里程计精度（0.27m 闭环已够用）
- 不做回环/全局优化（KISS-ICP 无回环，接受漂移）
- 不深挖 z 漂移（slip 场景 +2.5m 记录在案，后收尾）
- 不换 SLAM 方案（FAST-LIO2 等评估后置）

### 验收标准（量化）
| 项 | 标准 |
|:---|:---|
| 地图 | 一张可复用的场地 2D 占用网格 + 点云 PCD（rviz 回显正确） |
| 导航 | 场地内任意两点发 goal，车自主到达，终点误差 <0.5m |
| 避障 | 障碍物入场车绕行到达；人横穿车减速/停车/重规划 |
| 稳定 | 连续 3 次完整流程无人工干预 |

## 三、技术方案决策（先端到端的取舍）

| 决策点 | 快速方案（先用） | 正式方案（后补） |
|:---|:---|:---|
| 建图 | KISS-ICP PCD 累积 → 2D 投影（pointcloud_to_laserscan 或直接投影） | 回环/局部优化（后置） |
| 定位 | **KISS-ICP odom 顶替**（map 系 ≈ odom_lidar 系，跳过 AMCL） | AMCL（正式化） |
| 全局规划 | Nav2 SmacPlanner Hybrid-A* | 同 |
| 局部规划/避障 | Nav2 DWB（全向轮适配） | MPPI 对比 |
| 动态避障 | 激光阈值停车 demo（半天先出）→ local costmap 正式 | 同 |
| 底盘接口 | ros2_control 或直接 /cmd_vel 桥（最快） | ros2_control 正式化 |

> 原则: 先用最简单能跑的方案打通链路，正式化方案在闭环验证后再替换。
