## 三、几何模型与计算表

### 3.1 统一公式（[ros2-ops §12.1](../ros2-ops.md) 泛化到「装高 h × 倾角 α」）

```
最低射线仰角      β_min = α + θ½          （水平面下方为正）
盲区半径(打顶临界) d_blind = (h − t) / tan(β_min)      ← h < t 时无打顶盲区
地面覆盖带        近端 = h / tan(β_min)；远端 = α > θ½ 时 h / tan(α − θ½)，否则 ∞
反算（布站评价）   要覆盖距 d 处的顶高 t 目标：α ≥ atan((h−t)/d) − θ½
```

θ½：**VLP-16 15° ｜ MID-70 35.2° ｜ D435 29°**。适用边界：单垂直平面（正前方）；不含遮挡与点密度约束。

### 3.2 表 A：0.35m 箱顶盲区半径（m）

| h \ α | 0° | 10° | 15° | 20° | 30° | 40° |
|:--|--:|--:|--:|--:|--:|--:|
| VLP-16 @0.775（现装） | **1.59** | 0.91 | 0.74 | 0.61 | 0.43 | 0.30 |
| MID-70 @0.65 | 0.43 | 0.30 | 0.25 | 0.21 | 0.14 | 0.08 |
| MID-70 @0.60 | 0.35 | 0.25 | 0.21 | 0.17 | 0.12 | 0.07 |
| MID-70 @0.55 | 0.28 | 0.20 | 0.17 | 0.14 | 0.09 | 0.05 |

> **拟定装法（h 0.55~0.65、α 15~20°）把 0.35m 箱盲区从现装 VLP-16 的 1.59m 压到 0.14~0.25m**——低物盲区（L1）在几何上被基本消除。

### 3.3 表 B：地面覆盖带（近端~远端，t=0，m）

| h \ α | 15° | 17.5° | 20° |
|:--|:--|:--|:--|
| MID-70 @0.55 | 0.46~∞ | 0.42~∞ | 0.38~∞ |
| MID-70 @0.60 | 0.50~∞ | 0.46~∞ | 0.42~∞ |
| MID-70 @0.65 | 0.54~∞ | 0.50~∞ | 0.45~∞ |
| VLP-16 @0.775 | 2.89~∞（α=0） | — | — |

（α < θ½ 时远端为 ∞，实际受量程/入射角限制；α ≥ 35.2° 才收成有限带，见 [3d-lidar-2d-navigation-survey §三B](3d-lidar-2d-navigation-survey.md) 论文同型配置）

### 3.4 交叉验证（外部论文 → 公式吻合）

[MDPI Sensors 24(24):7929](https://www.mdpi.com/1424-8220/24/24/7929)（果园负障碍，MID-70 装高 0.8m、**倾角 40°**）：
报告盲区 **3m → 0.21m**、地面点云密度提升一个数量级；按其论文几何式代入 `0.8/tan(35.2°+40°) = 0.212 m`，
**与本文公式逐位吻合**。→ 公式可信，且"倾斜装法大幅改善近地覆盖"有外部实证。

## 四、拟定装法的垂直覆盖包络（近 / 中 / 远 × 最高 / 最低）

### 4.1 角度极值（与装高无关，只由 α 与 θ½ 决定）

| 项 | 表达式 | α=15° | α=17.5° | α=20° |
|:---|:---|:--|:--|:--|
| **最高射线**（视场上缘） | θ½ − α 仰角 | **+20.2°** | +17.7° | +15.2° |
| **最低射线**（视场下缘） | θ½ + α 俯角 | **−50.2°** | −52.7° | −55.2° |

对比 VLP-16：上缘 +15.0°、下缘 −15.0°。
> **关键**：MID-70 下俯 15~20° 后，**上缘反而比 VLP-16 高 0.2~5.2°**（70.4° 宽视场抵消了倾角损失）——
> 即"低头看近地"没有付出"看不到上方"的代价。

|:---|--:|--:|--:|--:|

**选参建议（按角色倾斜）**：

- **近地补盲优先**（低物/负障碍）→ h 低 + α 大：`0.55 / 20°`（地面 0.38m、箱盲区 0.14m）
- **建图 + 远距结构优先** → h 高 + α 小：`0.65 / 15°`（10m 处覆盖到 4.33m）
- **折中**（推荐区间）→ `0.60 / 15~17.5°`；**α 取 15° 而非 20°** 对上视/远距更有利，仅牺牲 0.04~0.08m 的近地

### 4.4 剩余盲区（拟定装法下仍然看不见的）

1. **贴地薄物**（t≈0，如 5cm 平板）：盲区 = 地面首着点 **0.38~0.54m**（不是 0.14m——0.14m 是 0.35m 高目标的打顶临界）
2. **车体正下方与正后方**：锥体朝前，不覆盖
3. **近距贴地段（无传感器覆盖 → 归行为层兜底）**：0.3m 水平距离处，MID-70 最低只到 0.21m、
   夹层 D435 最低只到 0.41~0.47m → **地面 <0.46m 与 0.3m 处 z<0.21m 全部传感器皆不可见**。
   D435 角色为视觉栈、**不承担低物检测**（§一），故该缺口**无感知手段可补** → 归
   **L4 行为层**（近距限速/停车兜底，[ros2-ops §12.2](../ros2-ops.md) 待决策项）

## 五、安装可行性核查

### 5.1 与 VLP-16 的互为遮挡（核算，**建议实测复核**）

- **判据**：正上方遮挡物造成的**遮挡起始仰角** `γ_block = atan(Δz / r)`（Δz=垂直间隙，r=遮挡物半径）——
  射线仰角 ≥ γ_block 才会被上方遮挡物截住；
- 取 r = 0.05~0.10 m（VLP-16 机体半径量级）、Δz = 0.13~0.23 m → **γ_block ≈ 52°~78°**；
- **MID-70 锥体上缘仅 +15.2~20.2° 仰角 ≪ γ_block** → **VLP-16 不遮挡 MID-70 上视** ✓
- 反向：VLP-16 最低环 −15° 到达 MID-70 所在高度（0.55~0.65m）时已水平推移 **0.47~0.84 m**，
  远超 MID-70 机体尺度（≤0.1m） → **MID-70 不遮挡 VLP-16** ✓
- ⚠️ 结论对"同柱上下叠装"成立；**若支架前伸/侧移，需按实际几何重算**
- ⚠️ 结论对"同柱上下叠装"成立；**若支架前伸/侧移，需按实际几何重算**

### 5.2 支架与 FOV 纪律（官方硬要求）

- **任何结构不得穿过 MID-70 锥体**（锥体朝前下方，±35.2°）：支架应从**后方/上方**引出；倾斜件避免伸入锥体
- 官方："FOV 不得被任何物体遮挡（含玻璃）"——车头前方不得有透明/半透明件挡在锥体内
- 若日后加装云台/机械臂，其停放位需避开该锥体

### 5.4 D435 车体位：三层叠装（VLP-16 0.775 / D435 夹层 / MID-70 0.55~0.65）核算

**(1) 覆盖影响**（h 取夹层代表值 0.70m；D435 垂直半角 29°）

| 项 | α=0° | α=10° | α=15° | α=20° |
|:---|--:|--:|--:|--:|
| 地面首着点（m） | 1.26 | 0.86 | 0.73 | 0.61 |
| 0.35m 箱盲区（m） | 0.63 | 0.43 | 0.36 | 0.30 |
| 上缘仰角 | +29° | +19° | +14° | +9° |
| z高 @3m（m） | 2.36 | 1.73 | 1.45 | 1.18 |

> **近地覆盖不是本机的评价指标**——D435 角色 = **视觉导航栈/工作栈**，**不用于低矮障碍检测**（§一）。
> 因此夹层高度带来的"近地覆盖弱于低位安装"（地面 0.73~1.26m vs 低位 0.54~0.72m）**不构成代价**；
> 反之**高装对 VIO 有利**（地面占比低、场景/墙面特征多、离地高不易积尘与碰撞），与视觉栈定位一致。
> **低物检测由 MID-70 承担**（§四）。

**(2) 互为遮挡核算**（判据：**遮挡起始角 = atan(Δz / r)**，射线角度超过该值才被挡；Δz=垂直间隙，r=遮挡物半径）

| 检查项 | 遮挡起始角 | 实际最大射线角 | 结论 |
|:---|:---|:---|:---|
| MID-70 是否挡 D435 **下缘** | 54.5°~77°（Δz 0.07~0.13m） | 29°+α：44°(α15) / 49°(α20) / 54°(α25) | ✅ **α ≤ 20° 安全**；α=25° 临界 |
| VLP-16 是否挡 D435 **上缘** | 38.7°~63.4° | ≤ 29° | ✅ 不挡 |
| D435 机体是否挡 MID-70 **上缘** | 65.8° | ≤ 20.2° | ✅ 不挡 |
| D435 机体是否挡 VLP-16 **下缘** | 59.0° | 15° | ✅ 不挡 |

**(3) 边界条件（三层叠装的硬约束）**

1. **D435 下俯角 ≤ 20°**——否则下缘开始被正下方的 MID-70 机体截住；若需更大俯角，把 D435 **前后错位**（前移）绕开
2. **层间垂直间隙 ≥ 0.07m 量级**——间隙越小遮挡起始角越松，越容易互相挡（上表按 0.07~0.13m 计算）
3. **三者支架均不得伸入对方 FOV**（MID-70 为官方硬要求；D435/VLP-16 同理）
4. **此位置是三机中 IR 互扰风险最高点**：D435 的 850nm 投影夹在两台 905nm 雷达之间（§八-6）
5. 机械：夹层高度预算 0.13~0.23m 内要塞下 D435（90×25×25mm）+ 支架 + 走线（USB）

## 六、应用评价

### 6.1 FAST-LIO2 建图

| 维度 | 评价 | 说明 |
|:---|:---|:---|
| 消息/去畸变 | ✅ **优于 VLP-16** | MID-70 原生 CustomMsg **每点时间戳**，deskew 更好（直击 KISS 旋转漂移痛点） |
| 外参 | ⚠️ **新增易错点** | MID-70→IMU 外参 = 平移 (0.36, 0.035, ~0.42)m **+ 倾角旋转 15~20°**（非单位旋转；现 VLP-16 外参旋转为零）——倾角配错 → 系统性倾斜畸变 |
| 几何适配 | ⚠️ 双面 | 加装后锥体 +17.7°/−52.7°，**地面点占比高**：近地结构密（0.46m 起，利于负障碍/低物）；但**地面主导会弱化水平自由度（x/y/yaw）约束**，需靠前方墙体（3m 处可见到 1.56m 高）支撑 |
| 与 VLP-16 关系 | ⚠️ **不能同喂一个 FAST-LIO2** | FAST-LIO2 为单雷达输入；双雷达需二选一或先合流（时间同步+外参）；roadmap §3.3 的"各喂一个消费者"仍成立 |
| 全向底盘适配 | ⚠️ 待实测 | R2 可横移/原地转，**前向 70° FOV 的约束弱于 360°**；IMU 耦合可部分补偿（08-24 VLP-16 版 FAST-LIO2 已验证旋转 <2°/平移 0.5%，可作基线对照） |
| 姿态建议 | — | 若主要目的是**喂 FAST-LIO**，α 取区间下限（**15°**）保上视；若主要目的是**补盲**，取 20° |

### 6.2 explore（前沿探索）等导航应用

| 维度 | 评价 |
|:---|:---|
| 2D 建图/前沿检测 | ✅ 中远距墙体覆盖与 VLP-16 相当（3m→1.56m、5m→2.20m 高），地面段更完整 → 2D 投影高度带（如 0.1~1.5m）可稳定出墙/边界 |
| 近距未知区 | ✅ 近地覆盖（0.46m 起）比 VLP-16（2.89m 起）**质变**；窄通道/门洞探索优势明显 |
| 负障碍（坑/台阶） | ✅ 倾斜装法强项（§3.4 论文即此用法），对探索安全性有增益 |
| FOV 局限 | ⚠️ 前向 70.4°，探索转向时需靠 360° 的 VLP-16 兜底（两雷达并存即为此） |
| 低带源复用 | ✅ 09-05/09-08 修法 B 的"低带源进 costmap"机制（velodyne_low 形态）可平移到 MID-70，且点更密（[retrospect 09-05](../retrospect/2026-09-05_lowobstacle_fixB_vm_acceptance.md)） |
| 与"离线先验地图"路线 | ⚠️ 若走 roadmap §二 的**离线阵营**（先验地图 + 重定位），MID-70 的价值更多在**建图前置**与**近距安全兜底**，而非在线探索 |

### 6.3 视觉导航栈（VINS 等）+ 两台 D435 分工

**关键约束：车体那台 D435 无内置 IMU**（D435i 已归还）→ 视觉惯性方案必须外接 IMU。

| 项 | 结论 | 依据/说明 |
|:---|:---|:---|
| VIO 可行性 | ✅ 可行，但需外接 IMU | VINS-Fusion / OpenVINS 均支持外部 IMU：配置 `imu_topic` 指向 R2 现有 G354 的 `/imu/data`，并给对噪声参数（acc_n/gyr_n/acc_w/gyr_w）与 `body_T_cam0` 外参 |
| 时间同步 | ⚠️ **最大工程风险** | USB 相机 vs 串口 IMU 无硬件触发 → 需离线标定（Kalibr 相机-IMU 联合标定）+ 在线估计时间偏移（VINS `estimate_td: 1`） |
| 图像流选择 | 建议用 **IR 双目**（全局快门） | D435 的 RGB 为卷帘快门；IR 双目全局快门更适合 VIO（D435i 缺席下更应如此） |
| 安装位 | **拟定位 = 两雷达间夹层（离地 0.65~0.775m），前视、下俯 10~15°**（≤20°，见 §5.4） | 该高度对 VIO 有利：地面占比低、场景/墙面特征多（地面首着点 0.73~0.86m @0.70m 装高）；近地覆盖的损失由 MID-70 承担（§5.4-1） |
| **角色边界** | **不承担低物检测**（09-16 用户明确）：本机 = 视觉导航栈/工作栈输入 | 低物与近地由 MID-70 承担；**近距贴地缺口（§4.4-3）不指望本机补**，归 L4 行为层。若日后确需近距深度避障＝新增需求，需重评安装位（前低位 0.3~0.45m/下俯 10~15° → 地面首着点 0.49~0.72m，参数留档） |
| 安装纪律 | 刚性、避振动、避自车入镜 | VIO 对振动与运动模糊敏感 |
| 与雷达协同 | 雷达-相机外参标定：**有 MID-70 是利好** | MID-70 高密度点云 → 走 [livox_camera_calib](https://github.com/hku-mars/livox_camera_calib)（roadmap §1.2 已定对口组合，官方示例即 Avia+D435）；VLP-16 稀疏，走 koide3 路线 |
| D435 #2（机械臂末端） | 预留，暂不评价 | eye-in-hand 手眼标定随机械臂集成另议 |

> **角色边界（2026-09-16 用户明确）**：车体 D435 = **视觉导航栈/工作栈**（VIO、视觉重定位、视觉探索等），
> **不用于低矮障碍检测**——低物由 MID-70 承担，近距贴地缺口归 L4 行为层（§4.4-3）。
> 该定位**反向支撑夹层装位**：高装地面占比低、场景特征多，正合 VIO；"近地覆盖不足"对本机不构成代价（§5.4）。

## 七、方案定位与倾向（a/b/c 对位）

拟定的"VLP-16 保留 + MID-70 下挂前倾"落在 roadmap §3.3 的框架内：

| 原方案 | 与拟定装法关系 |
|:---|:---|
| a. MID-70 换装主雷达 | ❌ 未采纳：VLP-16 保留（360° 用于 Nav2/AMCL） |
| **b. 双雷达组合** | ✅ **拟定装法即 b 的落地变体**：VLP-16 360° 全景 + MID-70 补盲/密度 |
| c. VLP-16 + D435 补近距 | ❌ **未按原义采纳**：D435 仍在车上，但角色为**视觉导航栈**、不补近距（低物由 MID-70 承担，§一/§六.3） |
| d.（本文前版补充）MID-70 大倾角地面扫描 | ➖ 15~20° 是其"温和版"：保留上视 +15~20°，牺牲部分贴地覆盖 |

**评价结论**：拟定装法 = **b（双雷达）+ d 的折中姿态**，几何上是合理中间态——既把低物盲区从 1.59m 压到
0.14~0.25m，又保住上视/远距结构（10m 处覆盖到 3.3~4.3m）。

> **用户 2026-09-16 确认**：后续大概率采用 **b（双雷达组合）+ 车体一台 D435**（D435 夹在两雷达之间，§5.4）。
> 因此 a/c 两条仅作记录；**待验证项**集中在 §八：外参（含倾角旋转）、N97 算力、双雷达互扰、
> 三层叠装的机械实现、以及"地面点占比升高对 LIO 水平自由度的影响"。
