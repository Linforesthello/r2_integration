## 一、车体坐标系（REP-103）

```
        前 (x⁺)
         ↑
   左 ←───┼───→ 右      y⁺ 左, z⁺ 上
         ↓
        后
```

| 轴 | 正向 | 说明 |
|:--:|:-----|:-----|
| x | 车前 | 前进方向 |
| y | 车左 | 侧向 |
| z | 车上 | 竖直向上 |

## 三、模块安装

### 3.1 G354 IMU

| 项目 | 值 | 说明 |
|:-----|:---|:-----|
| 安装位置 | **(-43, -3.5, +20.0) cm**（base_link 系） | ✅ **2026-11-08 复测（G10）**：(-43, -3.5) cm，距地 32cm − base_link 12cm = +20.0cm。旧值保留：08-24 测 (-36, -3.5, +18.5)（按距地 30~31cm）——**IMU 物理位置未变**，两次数值差 1.5cm 来自测量口径/读数，以 11-08 为准。静态 TF 当前仍为单位变换，平移待补齐（FAST-LIO 外参仍用 08-24 值，见 [fastlio2-n97-deploy.md](../n97/fastlio2-n97-deploy.md) §三.1） |
| 传感器轴向 | **x 朝车左、y 朝车前、z 朝车下** | **G354 出厂轴定义**（模块正放安装即此朝向，非标准 REP-103） |
| 驱动参数 | `mount_axes:=y_front_x_left_z_down` | imu_node 内做轴映射（传感器系→车体系） |
| 静态 TF | 单位变换（旋转为 0，因数据已映射到车体系） | 平移待基准确认后补齐 |

**传感器轴系**（G354 出厂定义，模块正放时相对车体）：

```
    传感器 y → 车前(x⁺)
    传感器 x → 车左(y⁺)
    传感器 z → 车下(z⁻)
```

### 6.1 LD06 #1 安装几何（✅ 2026-11-08 实车量测，G10）

> 量测基准：base_link = 底盘正中心、离地 12 cm；x 前 / y 左 / z 上。原始输入见
> `doc/raw_data/raw_g10_mount_measure_2026-11-08_1604.md`（本地，不入 git）。
> 唯一消费方 = [`ldlidar_stl_ros2/launch/ld06.launch.py`](../../ldlidar_stl_ros2/launch/ld06.launch.py) 的静态 TF 默认值。

| 分量 | 实测 | 折算到 base_link | 说明 |
|:---|:---|:---|:---|
| `x` | +27.5 cm | **+0.275 m** | 雷达在底盘中心前方 |
| `y` | +29 cm | **+0.290 m** | 在底盘中心左侧（y 正 = 车左） |
| `z` | 光学中心离地 16 cm | **+0.040 m** | 16 − 12（base_link 离地）；比低框架平面（离地 10 cm）高 6 cm |
| `yaw` | 模块 0°（顶部 △）指向车体 **−y** | **−1.5708 rad（−90°）** | 推导见下 |
| `pitch` / `roll` | 未单独量测 | **0**（按水平安装） | 若实车有倾角需补测 |

**yaw 推导（原始角 ↔ 发布角差一个镜像，勿混用）**：

1. 手册 §4（`~/Lin_Product_information/乐动雷达/LDROBOT_LD06_Development_Manual_CN_v2_20220530145622.3.pdf`，第 10 页）：
   左手系，**0° = 模块正前方（顶部 △ 标记）**，角度**顺时针**增大；
2. 实车安装：△ 指向车体 −y → 车头（+x）在雷达**原始角** = 顺时针 270°；
3. 驱动 `laser_scan_dir=true` 时 `index_anticlockwise = beam_size−index−1`，
   **发布角 = 360° − 原始角**（11-07 N97 crop 实测：crop `[0,90]` → 发布侧 269.4~360.8°，
   见 [ld06-dual-lidar.md §三 P7](../old-car/ld06-dual-lidar.md)）→ 车头物体在 `/scan` 读 **+90°**；
4. 反推 TF：`base_laser` 的 +x = 模块 △ = 车体 −y ⇒ `Rz(ψ)·(1,0,0)=(0,−1,0)` ⇒ **ψ = −90°**；
   核对：车头物体在激光系角度 = 0° − ψ = +90°，与发布角一致 ✓。

> ⚠️ **未复核项**：yaw 由「手册 + △ 朝向」推导，未用实物读数验证。首跑时把目标放车正前方约 1.5 m，
> `/scan` 应读到 **≈ +90°**；若读到 −90°/0°/180°，说明 △ 朝向判断或镜像假设有误，先改这里再建图。

**LD06 供电/接触（2026-11-06 首测记录）**：VM 首次验证运行 **18 min 36 s** 后雷达蓝灯灭/停转，驱动连续报
`get ldlidar data is time out`；重启后串口可开、`Actual BaudRate reported:230400`，但 3 s 内无有效帧 →
`ldlidar communication is abnormal`（exit 1）；重新插拔供电后恢复。判断为 **LD06 本体掉电/供电接触瞬断**，
非驱动/波特率问题。S1 前须：带载测 PSV 对 GND 电压（手册 4.5~5.5 V）、检查 ZH1.5T-4P 的 PSV/GND 接触与
共地、确认 5V 来源带载能力；装车后做 ≥30 min 长跑复现。原始日志见
`doc/raw_data/raw_ld06_power_loss_2026-11-06_1424.txt`（本地留档，不入 git）。事件复盘与冒烟证据见
[2026-11-06 LD06 VM 接入与冒烟](../retrospect/2026-11-06_ld06_vm_bringup_smoke.md)。
