# Obsidian 标签体系习惯

> 维护者：所有在 Obsidian 库打标签的人
> 适用范围：`~/Lin_note/Open-Notes-Library/`（✨分天、✨总 等全部笔记）
> 数据来源：库内实际标签统计（2026-08-02 归纳），新增/修改标签前先读本文件

---

## 一、基本结构：行内分层标签

标签写在笔记正文（通常文件顶部），用 `#` 开头、`/` 分层：

```
#顶层/二级/三级/...
```

示例：`#Problems/solving/ROS/ros下找不到头文件`、`#待/做/已实现/20251230`、`#VMware/死机/更改磁盘`

- 不写进 YAML frontmatter，直接作为行内文本
- 层级 2~4 层，按需细化，不强行拉满
- 一个文档 2~3 个标签，从不同维度覆盖（问题类型 + 技术领域）

---

## 二、顶层分类（不要新建顶层，优先复用）

| 顶层 | 用途 | 分支习惯 |
|:-----|:-----|:---------|
| `#Problems/` | 问题/坑记录 | `recurring`（反复）· `solving`（已解决）· `unsolved`（未解决）· 直接主题 |
| `#待/` | 待办/任务状态 | `做` · `看`，第三层接状态或日期（`已实现/YYYYMMDD`） |
| `#Tools/` | 工具使用技巧 | 具体工具名 → 细分（`git/分支`、`工具链/linux`、`skills/ai`） |
| `#lidar/` `#depth_camera/` `#imu/` | 传感器 | **型号_ros版本**（`LD06_ros1noetic`）→ 主题 |
| `#SLAM/` | SLAM 方案 | **算法名**（`RTAB`、`Hector`、`Gmaping`、`kiss_icp`） |
| `#STM32/` `#Rasp/` `#VMware/` `#计算机板卡/` | 平台/硬件 | 平台 → 功能主题（`tim/encoder`、`死机/更改磁盘`、`radxa/a7z`） |
| `#控制/` `#电机/` `#底盘/` | 运动控制领域 | 领域 → 具体对象（`车体控制`、`轮趣dm50电机`） |
| `#优化/` | 代码/流程优化 | `开发流程` · `代码组成` · `代码架构` → 细节（`路径管理`） |
| `#回顾/` | 复盘/复现 | `复现` → 主题（`解决遗留问题`） |
| `#ROS/` | ROS 生态 | 功能/工具（`rviz`、`仿真项目`、`launch`、`Linux常用指令`） |
| `#长期项目/` `#规划/` `#Robocon2026/` | 项目/时间维度 | 项目名或 `YYYYMM` |
| 学习类 | 书籍/课程/知识 | `书籍配套/RVC3`、`Matlab/Control`、`C语言/基本语法`、`深蓝课程` |

**单层标签**（`#python`、`#docker`、`#网络`、`#烧录` 等）可用于日常日志随手标记，但正式文档优先用分层标签。

## 三、命名约定

| 规则 | 说明 | 示例 |
|:-----|:-----|:-----|
| 中文词 | 语义层用中文 | `代码架构`、`路径管理` |
| 英文小写 | 技术词用英文小写 | `ros1noetic`、`kiss_icp`、`tim/encoder` |
| 日期 | `YYYYMMDD` 或 `YYYYMM` | `20251230`、`202509` |
| 长名称 | 下划线连接 | `Astra_Pro_ros1noetic`、`OMF_Feedback及其合理化衍生` |
| 叶子层 | 具体主题词，不写宽泛词 | `频率` ✅、`Queue` ✅、`问题` ❌ |

## 四、打标签流程

1. 先查本文件顶层分类，**优先复用现有标签**，只允许新增叶子层（`#顶层/已有二级/新叶子`）
2. 已解决的问题用 `#Problems/solving/...`，未解决用 `#Problems/unsolved/...`，反复出现用 `#Problems/recurring`
3. 传感器/算法有现成型号、算法名的直接对齐（`#lidar/vlp16`、`#SLAM/kiss_icp`）
4. 情绪/状态类标签归 `#日常/`（`#日常/生气`、`#日常/正式休息`）；人名标签可保留单层（如 `#李震`）
5. 同文档 2~3 个标签，覆盖"问题维度 + 领域维度"

## 五、镜像同步注意

`r2_integration/doc/` 的文档会单向同步到 Obsidian 镜像 `R2_Integration/doc/`。
**标签只加在 Obsidian 镜像侧**（镜像 = 权威源内容 + 标签增强），权威源保持纯文档；
同步时用 `cp` 覆盖镜像即可，不会丢标签。
