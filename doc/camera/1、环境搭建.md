## 1、环境搭建

### 1.1、安装相关依赖

终端输入，

```bash
sudo apt install libgflags-dev  ros-$ROS_DISTRO-image-geometry ros-$ROS_DISTRO-camera-info-manager ros-$ROS_DISTRO-image-transport ros-$ROS_DISTRO-image-publisher libgoogle-glog-dev libusb-1.0-0-dev libeigen3-dev nlohmann-json3-dev
```

### 1.2、安装libuvc

终端输入，

```bash
git clone https://github.com/libuvc/libuvc.git
cd libuvc
mkdir build && cd build
cmake .. && make -j2
sudo make install
sudo ldconfig
```

### 1.3、编译功能包

建立好工作空间（这里以astra_ws为例），解压文件夹，得到ros2_astra_camera文件夹，把这个文件夹copy到工作空间的src目录下，然后输入以下指令进行编译，

```bash
cd ~/astra_ws 	#这里的我工作空间是在~目录下的，根据自己的工作空间目录进行修改
colcon build --event-handlers  console_direct+  --cmake-args  -DCMAKE_BUILD_TYPE=Release
```

编译需要一点时间，请耐心等待。

### 1.4、安装libusb规则

终端输入，

```bash
cd ~/astra_ws/src/ros2_astra_camera/astra_camera/scripts  #这里的我工作空间是在~目录下的，根据自己的工作空间目录进行修改
sudo chmod 777 *
sudo bash install.sh
sudo udevadm control --reload-rules && sudo udevadm trigger
```

### 1.5、添加环境工作变量

编辑~/.bashrc文件，把以下语句加在最后一行，终端输入，

```bash
sudo vim ~/.bashrc
source ~/astra_ws/install/setup.bash	#把这句加在最后边，这里的我工作空间是在~目录下的，根据自己的工作空间目录进行修改
```

保存退出后，重新source一次终端。

### 1.6、运行相机

把相机接在主板或者电脑上，如果是虚拟机，则需要保证的是USB3.0的连接，

![image-20230301095857909](image-20230301095857909.png)

终端输入，

```bash
ros2 launch astra_camera astra_pro.launch.xml	#astrapro相机
ros2 launch astra_camera astra_pro_plus.launch.xml	#astraproplus相机
```
