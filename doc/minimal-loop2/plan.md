## 一、目标与范围

### 做（串行，做完一项走下一项）

1. **第一个闭环收尾**：W3 避障验收（minimal-loop 遗留）
2. **FAST-LIO2 落地**：TF 桥集成 + 建图源平替 KISS（08-24 实车验证全项通过 → 从"评估"转"落地"）
3. **RL 方向部署**（降级执行）：环境跑通 + 概念讲清，完整复现曲线留给秋招后
4. **新架构尝试**（有余力选一）：explore_lite 探索 / D435 视觉接入

### 不做（后置/不碰）

- 单环节精度精化：LI-Init 外参精标、平整场地高精度复测、严格直线量测——全推迟（面试叙事吃链路不吃精度）
- 多线并行：同一时刻只有一条线，不铺开候选池（01-plan §8.4 候选池继续冻结，做完 B2 才解锁）
- 传感器 A/B（VLP-16 vs MID-70）：推迟（VLP-16 现状够用，换装是工程不是叙事）
- 08-26 之后不新增 R2 功能（硬截止，防执行偏差复现）

## 三、验收原则（全面但阈值，不苛刻）

- **全面**：每个方向都有量化数据（区别于"跑通即通过"的空话）
- **阈值**：达标即过，不追精度（平移 <5% 而非 <1%；旋转 <2°；避障 3/3；探索覆盖率 >80%）
- **范式参照**：08-24 FAST-LIO2 验收（旋转 <2° + 平移双口径 0.51%/0.58%）即为正确样板
