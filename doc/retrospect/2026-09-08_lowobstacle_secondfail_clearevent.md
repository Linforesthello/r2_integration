## 一、结论（先行）

第二次（及以后）接近失效的根因 = **新 goal 下达时 global costmap 障碍观测层被一次性整体清空（ClearEntirely 特征），把第一次接近时保留下的箱子 mark 全部抹掉；而箱子此时已在几何盲区（<1.59m 临界，-15° 环越顶不可再观测），mark 无法再生 → costmap 对箱子全空 → 车直行穿越**。

排除了此前三个假设：

| 假设 | 判定 | 证据 |
|:---|:---|:---|
| H1 配置未加载（修法 B 没生效） | ❌ | 窗 A 停车后静止 9.5s，global 车头 ROI254 稳 228~274 不衰减 → mark-only 保留语义工作正常 |
| H3 层隔离在真实链路失效 | ❌ | 保留 mark 在静止期始终在，local 全程无清除、无异常衰减 |
| H4 位姿重置/costmap 重置（AMCL 跳变） | ❌ | map→odom tf 167→172s 平滑（(0.8138,0.3725,-13.14°)→(0.7936,0.3642,-13.31°)）；global origin/size 全程不变 |
| **新根因：障碍层整层清空事件** | ✅ | 见 §二 |

## 三、因果链（完整闭环）

1. 第一次接近（窗 A，153.5~160.5s）：车在 >1.59m 处多次命中箱子 → 低带源 mark 建立；160.5s 停在 map(3.12,0.15)（箱距 ~1.0m）
2. 停车时箱子已 < 1.59m 临界 → **进入绝对盲区**：-15° 环从箱顶越过，低带源此后物理上不可能再观测到箱子（几何定律，09-08 ring 律 1.59m）
3. mark-only 修复（180077c）让已保留 mark 在静止期存活（窗 A 实证 228 稳定 9.5s）→ 此刻若不再有清空事件，第二次接近本该还能看到
4. **169.13s goal6 下达 → global obstacle 层整层清空（≈169.5~170.0）→ 保留的箱 mark 全数抹掉**（箱区 −52%）
5. 第二次接近（窗 B，170.2~178s）全程箱距 ≤1.0m < 1.59m → 无任何新 mark 可能；前窗 ROI254 重积累的全是墙面重新标记（质心 map 4.2→5.8 = 东墙），箱位永不恢复
6. 车沿"已清空"路径直行，178s 停在 goal6 前 0.26m（容差内视为到达）→ 用户观察 = "直行不管箱子"

## 四、对后续决策的含义（供用户定夺，非建议倾向）

- 修法 B（mark-only 保留）**在无清空事件时正确工作**，但**任何一次 global 障碍层整层清空都会把它打回原形**，而箱在盲区内无法重新观测 → 该修复对"第二次接近"场景是脆弱的（可被导航自身恢复机制意外抹除）
- 物理边界（1.59m 盲区临界）不因修复改变：保留 mark 是该边界下唯一信息源，而它可被一票清除
- 与用户抛出的方向问题相关：低物检测在不加传感器前提下的确接近感知极限；本事件补充说明即使保留机制修好，**导航栈自身的 clear 语义与盲区保留存在结构性冲突**，工程上还需处理"清空后如何保住箱位"（如独立静态代理层/禁止 planner-fail 清 global/接近段禁 clear），属变通而非根治

## 五、方法模板节

本次 bag 逐帧定位"单帧清除事件"的可复用操作卡：

1. ① 时间线先粗后细：t1 速度/goal/plan 全览锁定运动段 → t2 统一 map 系几何 → t3 地图上下文
2. ② 减速窗逐帧取证：t4 每帧 costmap 输出 ROI254/253/质心/全图 254 + 车距（不要整图 diff，用固定前窗计数——09-06 E9 教训）
3. ③ 可疑单帧 → 帧间 cell diff 量化：消失/新增格数、消失 bbox、消失格空间分布（t5）→ 判断"局部衰减 vs 整层清除"（本案例 8870−6634=2236 = 全部非静态 254 = 整层特征）
4. ④ 排除机制三查（t6）：costmap origin/size 逐帧（重初始化？）+ 相邻 costmap 同窗对照（只清 global 还是双清）+ map→odom tf 高分辨时序（AMCL 跳变？）
5. ⑤ 事件对齐：goal/plan 时间戳与清除帧同刻比对 → 恢复链判定（planner 失败空窗 → clear → 新 plan）
6. ⑥ 物理闭合：用 ring 几何律验证"清除后为何不可再生"（盲区距离判据），完成因果链
