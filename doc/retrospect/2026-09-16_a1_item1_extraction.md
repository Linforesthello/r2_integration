```text
① 定未抽清单   逐条判「成熟 / 未成熟」：成熟者定落点，未成熟者在 draft 标理由 + 成熟条件（本次 B1~B3）

               不硬塞既有小节；域外条目（如 E5）单列请示，由用户裁定落点
③ 抽取写规则   规则层只写「规则形态 + 来源回指」（短条款），细节/数值/操作卡留来源事件档或唯一事实源文档
④ draft 收薄   已抽条目正文本替换为状态回指块（保留主题骨架 + 来源回指 + 「无未抽条目」声明）；
               未抽条目全文保留 + 落盘未抽理由
⑤ 连带同步     权威树（README 树 + 规范头部范围行）+ 引用方双向互指（数值源 ↔ 判据层）+ 状态板三处 + 状态表刷新
⑥ 闸门验收     校验器（本次致坏 = 0）+ 条数口径写死 + 双仓（先 diff/rsync 复验，再 commit/push）
```
