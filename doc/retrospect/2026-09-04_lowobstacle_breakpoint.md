## 二、方向修正（关键教训：先定符号约定，别被现场反推推翻标签）

- ROS LaserScan 标准：**正角度 = y>0 = 车体左侧；负角度 = y<0 = 车体右侧**，与 points atan2(y,x) 同口径
- 初期分析把负角（-10.5°~-0.5°）一律当「车体左侧/左前」报告 → 用户质疑「我一般从车体右侧经过，
  怎么所有被检物体都在左侧」→ 用 points 逐点 y 符号 + atan2 复核：**负角 = 右侧**，此前全部「左」解读反转
- 修正后场景几何自洽：右前 = 用户操作区（箱子、人、低物全部 y<0）；左墙近（x≈1.2, y≈0.86 → +35°+），
  +10.5°~+14.5° 恒定 3.2~3.7m（斜墙/墙后物）；0° 附近 = 5.4m 通道尽头（开阔基准 5.42~5.59m）
- 印证：points 锚定 4m 箱 y=-0.32（az -4.7°）、2m 箱 y∈[-0.40,-0.10]，全是右侧 ✓
- 教训：**方位角标签在动手分析前先用 points 符号校验一遍**；归档文档事后 grep 确认无 left/right 污染（0 残留）

## 七、可复用规则建议（本会话沉淀，**待授权后落 ros2-ops.md §5**，未获批不写入规范）

1. **帧间 diff 禁用 max(generator)**：序列含 nan（inf-inf 产生）时 `max()` 保留首个 nan → 阈值比较恒 False
   的静默 bug。显式 list 收集 + `isfinite` 跳过双 nan/inf，inf↔finite 切换显式计为大变化
2. **PointCloud2 读取按 field 解析**：point_step 含非 float32 字段（如 ring=uint16、time=float32）时
   numpy reshape 直接炸；用 uint8 view + msg.fields offset/datatype 逐 field 提
3. **方位符号先验校验**：LaserScan 正角 = 左（y>0）；分析前用 points 的 y 符号/atan2 校验方位约定，
   不要等现场操作习惯来反推标签
4. **聚类断段判据**：1° 带平均距离会把相邻驻留混成假 avg；用 0.1m 档跳变 >0.3m 断段可得到干净稳定表
