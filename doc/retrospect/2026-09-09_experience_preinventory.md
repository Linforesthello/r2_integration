## 四、方法模板（可复用：批量预盘点流程）

```text
① 定范围与切批   范围=全 doc；按「时间块+目录域」切批（单批 ≤~15 篇源文档）；底层源文件只读不拆不动
② 批内统一输出   候选六列表（编号/候选/类型/来源/建议去向/备注）+「已规则化核对」段 +「零增量确认」段；弱候选照登
③ 汇总分桶呈报   全批返回后按主题分桶编号，一次性呈报；批准前不动任何文件；批准以桶编号回执
④ 落地二分 commit 经验/规则回写（只增不删+来源回指）与结构修复分两批——审阅面清晰、可独立回滚
⑤ 交叉核缺独立批 主线看板/索引/引用滞后单批专查——承载文档自洽 ≠ 全局同步
⑥ 底稿与收口     底稿入 raw_data + 文末「执行落账」节；处置（升格/清理）当场约定；
                 登记（retrospect/README + 根 README 树）+ 校验器本次致坏 = 0
```
