## 一、背景

旧建图包全部在频率波动下录制（0811 包 KISS 5.24Hz、102 处 >0.5s 空窗、帧间位移最大 65.7cm）：
掉帧 = 丢 azimuth 扇区 + 帧间大位移 → 地图点密度不均、局部拖花。08-15 VLP-16 链路调优稳定后
（points 9.3~9.4Hz），重录一张干净包作 D4/Nav2 地图基线。

## 二、链路稳定性验证（stats_map_run.py，新旧包对比）

| 指标 | 0811 旧包 | **165547 新包** |
|:---|:---|:---|

| 帧间隔 p50 / p90 / max | 101 / 304 / 2724 ms | **101 / 101 / 302 ms** |

## 三、空地散点溯源：建图时在场的人

地图"空地散点"经分析确认是**建图时跟在车后的人**（新旧两图独立验证）：

| 特征 | 实测 | 说明 |
|:---|:---|:---|
| 地图主体 | 散点仅 0.01% | 真结构每格 300~400 点，坚实 |
| 人形块 z 跨度 | 0.1 → 1.8~2.1 m | 腿→躯干→头 = 人站立高度 |
| 人形块宽度 | 0.5~0.7 m（5~14 格） | 肩宽 + 走动拖影 |
| 点密度 | 5~50 点/格 | 真结构 300+ |
| 重复模式 | 旧图 x≈6.2 y≈7.7~9.1 有 8 个同位小块 | 人同一位置站过多次 |

低矮密集块（400 点/格、z 0.06~0.15m）为路缘/地面凸起 = 真障碍，**不可删**。

## 四、工具与结果

新工具 `~/Lin_workspace/r2_integration/bags/analysis/filter_person_blobs.py`：
对 cum_100_900 + layer_900_1400 占用格的 2~16 格连通块，判据 = z 跨度 ≥0.8m 且点密度 <100/格
→ 判定人形块，删除其全部点 → 输出 clean ply → 重跑 layer_map.py。

```bash
python3 filter_person_blobs.py seg1_raw.ply --layers layers --out seg1_clean.ply
python3 layer_map.py seg1_clean.ply --outdir layers_clean
```
