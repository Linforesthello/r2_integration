## 二、处理链

```
seg1/2/3_raw.ply (binary LE xyz float, 每段 120~150 万点)
  → 每段地面 z0 对齐 (z 直方图峰值: seg1/3=0.025, seg2=0.055, 各段独立减)
  → 多段 XY 对齐 (旋转粗搜 ±4° 步长0.5° + FFT 互相关平移精搜, 以重叠区 IoU 最大)
  → 统一栅格 421×666 @0.05m (21.05m × 33.30m)
  → 按层高 [lo,hi) 切片: 格内 ≥1 点=占用, 孤立单格噪点清洗(连通块≥2)
  → 每层指标 + 对比图 + 三态版 (0占用/100自由/127未知) + yaml
```

工具：`bags/maps/map_final_0813/layer_map.py`（数据同目录，随数据存放），
可复用：`--layers`（分层边界）、`--body`（机体层带）、`--res`、`--min-pts`、`--align`。

## 四、排障记录

### 1. 既有 seg*.pgm 约定之谜（未解，弃用）

- seg2.pgm 黑区 183,721/188,195 格（97.6%），且 165,808 格在点云覆盖之外
- 试过 map.yaml origin、数据 bbox origin、上下翻转、min-pts 1/2，白色格与占用层 IoU 全 ≤0.06
- 结论：与原始点云无对应关系（可能生成方式/来源不同），本次弃用，改用标准约定 0=占用黑/100=自由白

### 2. 孤立噪点清洗 bug（已修）

首版 `np.isin(lbl, np.where(sizes>=2))` 把标签 0（背景，占绝大多数）也保留 → 全图变占用。
修正：`keep[1:] = sizes[1:] >= 2`，背景标签排除。

### 3. 三态未知值 205 坑（已规避，重要）

- 直觉 205=灰=未知，但 205/255=0.804 > occupied_thresh 0.65 → map_server 判为**占用**
- 未知区间实际是 (free_thresh, occupied_thresh) = (0.25, 0.65) → 像素 64~165，取 **127**
- 未观测区（黑色地面无回波，占 bbox 大部分）在三态版里为 127；二值版里为自由（与既有工作流一致）

### 4. 图片查看通道故障（工具限制，非数据问题）

本会话 Read 图片工具反复 "Unsupported Image"（仅首张成功），对比图未做 AI 目检；
数值验证（IoU/连通区/像素分布）已通过，图由用户本地查看。
